## Likelihood

### Gaussian Log-Likelihood
Assuming a set of data $x \in R^n$ generated by a gaussian distribution with parameters $\theta$, the Likelihood is given by
$$ L(\theta) = P(x|\theta) = \frac{1}{(2\pi)^{n/2}|\Sigma|^{n/2}}\exp\left( -\frac{1}{2}(x-\mu)^T \Sigma^{-1}(x-\mu) \right) $$
where $\mu$ is the mean and $\Sigma$ is the covariance matrix. 
For i.i.d. data
$$ L(\theta) = \frac{1}{(2\pi\sigma^2)^{n/2} } \exp\left( -\frac{(x-\mu)^2}{2\sigma^2} \right)$$
In particular, for one-dimensional, zero-mean, i.i.d. residuals the log-likelihood reads
$$ \log L(\sigma^2) = -\frac{n}{2}\log(2\pi \sigma^2) - \frac{1}{2\sigma^2} \sum_{t=1}^n \epsilon_t^2 $$
The maximum likelihood estimator for $\sigma$ is $\hat \sigma^2 = \frac{1}{n} \sum_{t=1}^n \epsilon_t^2$, thus $-\frac{1}{2\sigma^2} \sum_{t=1}^n \epsilon^2_t = -\frac{1}{2\sigma^2}n\hat \sigma^2 \sim -\frac{n}{2}$, therefore for residuals
$$ \log L(\sigma^2) = -\frac{n}{2}\log(2\pi\sigma^2) - \frac{n}{2} $$

### T-student Log-Likelihood
In presence of outliers or heavy tails it is better to assume residuals generated by a T-student distribution (Kurtosis $\gg 3 $, Q-Q plot non-linear). Assuming $\nu>0$ degrees of freedom and $\sigma^2$ scale (where $var = \frac{\nu}{\nu-2}\sigma^2$ for $\nu > 2$)
$$ L(\theta,\sigma^2,\nu) = \prod_{t=1}^n \frac{\Gamma(\frac{\nu+1}{2})}{\Gamma(\frac{\nu}{2}\sqrt{\nu\pi\sigma^2})}\left( 1 + \frac{x_t - \hat x_t(\theta)}{\nu\sigma^2}\right)^{-\frac{\nu+1}{2}}$$

## Information Criteria
### AIC
The Akaike Information Criterion is a method for model selection that balances goodness of fit with model complexity
$$AIC = -2\log L_{\text{max}} + k$$
where $L_{\max}$ is the maximum likelihood and k is the number of estimated parameters. The model with lower AIC is the best model.

### BIC
The Bayesian Information Criterion is a criterion for model selection that penalizes model complexity more strongly than AIC
$$BIC = -2\log L_{\text{max}} + k \log n$$
where $n$ is the number of sample. BIC is consistent, in the sense that if the true model is a candidate it will be selected for $n \to \infty$. Use BIC when we expect the true model to be a candidate and when the sample size is big, use AIC when we focus on predictive accuracy or the sample size is small.
